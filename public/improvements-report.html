💫 تحسينات الأنميشنات

✨ bounceClick() - تأثير الضغط العالمي

تأثير ضغط احترافي يطبق على جميع العناصر القابلة للنقر. عند الضغط:
• انضغاط للحجم 0.92
• وميض أبيض شفاف 48%
• حركة عمودية 2px
• ارتداد نابضي عند الإفلات

modifier = Modifier.bounceClick()

🎯 ElasticEntrance() - دخول مرن

العناصر تدخل بتأثير مطاطي يتجاوز الحجم الطبيعي ثم يستقر:
• بداية من 50% من الحجم
• مدة 480ms
• منحنى مرن مخصص elasticOutStrong
• تأخير متدرج 70ms بين العناصر

🕰️ SwingCardEntrance() - تأرجح الساعة

البطاقات تدخل بحركة دوران كعقرب الساعة:
• دوران من -12° إلى 8°
• ارتداد معاكس -3°
• استقرار نهائي بنابض ناعم
• تقليص طفيف 95% أثناء الدوران

🌈 animatedGradient() - تدرج حي

تدرج لوني يتنفس ويدور ببطء:
• ثلاث درجات لونية متداخلة
• مدة 9 ثوانٍ للدورة الكاملة
• دوران تدريجي لاتجاه التدرج
• انتقالات سلسة بين الألوان

🔢 AnimatedNumber() - عداد ذكي

الأرقام لا تقفز بل تعد تصاعدياً:
• مدة ديناميكية 200-500ms
• وميض أخضر عند الزيادة
• ضباب خفيف أثناء العد (Android 12+)
• سلاسة بمنحنى FastOutSlowIn

⚙️ ثوابت الحركة AppMotion

معايير الحركة الموحدة

تجميع جميع قيم الأنميشن في مكان واحد للاتساق:

STAGGER_STEP_MS = 70ms // تأخير متدرج
springBounce // نابض منتصف الارتداد
springGentle // نابض ناعم بدون ارتداد
elasticOutStrong // منحنى مرن قوي
shimmerColor // لون الوميض الأبيض

rememberReduceMotion()
