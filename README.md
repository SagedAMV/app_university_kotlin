# UniManager - تطبيق مدير الجامعة (Kotlin/Android)

تطبيق Android أصلي لإدارة ملفات الجامعة، المحاضرات، المهام، الملاحظات، والامتحانات.

## المميزات

- ✅ **7 أقسام رئيسية**: الرئيسية، الملفات، المهام، الملاحظات، الامتحانات، الجدول، المجرة
- ✅ **قاعدة بيانات Room** لتخزين محلي سريع وآمن
- ✅ **Jetpack Compose** لواجهة مستخدم حديثة وسلسة
- ✅ **دعم RTL** كامل للغة العربية
- ✅ **الوضع الليلي** تلقائي
- ✅ **فتح جميع أنواع الملفات** (PDF, DOCX, XLSX, PPTX, صور, فيديو, صوت)

## التقنيات المستخدمة

- **Kotlin** - اللغة الأساسية
- **Jetpack Compose** - واجهة المستخدم
- **Room Database** - قاعدة البيانات المحلية
- **Coroutines & Flow** - البرمجة غير المتزامنة
- **Material 3** - التصميم
- **Apache POI** - قراءة ملفات Office
- **Media3 ExoPlayer** - تشغيل الفيديو والصوت
- **Coil** - تحميل الصور

## كيفية البناء

1. افتح المشروع في **Android Studio** (إصدار 2024.1 أو أحدث)
2. انتظر حتى ينتهي Gradle Sync
3. اضغط ▶ Run لتشغيل التطبيق على الجهاز أو المحاكي

## متطلبات النظام

- **Android Studio**: 2024.1+
- **JDK**: 17
- **Android SDK**: API 35 (Compile), API 26 (Minimum)
- **Gradle**: 8.7

## هيكل المشروع

```

├── app/
│   └── src/main/
│       ├── java/com/unimanager/app/
│       │   ├── MainActivity.kt
│       │   ├── UniApplication.kt
```
