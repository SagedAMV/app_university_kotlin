# UniManager - تطبيق مدير الجامعة (Kotlin/Android)

تطبيق Android أصلي لإدارة ملفات الجامعة، المحاضرات، المهام، الملاحظات، والامتحانات.

## 🎨 التحسينات الجديدة (2026)

- ✨ **أنيميشنات محسّنة**: أنيميشنات دخول وخروج سلسة للعناصر
- 🎭 **تصاميم عصرية**: بطاقات محسّنة مع تأثيرات بصرية جذابة
- 🌈 **تأثيرات Shimmer**: تأثيرات نابضة على البطاقات الرئيسية
- 🎯 **Bottom Navigation محسّن**: أنيميشنات دوران وتكبير عند التنقل
- 🌟 **Galaxy Screen محسّن**: تأثيرات توهج محسّنة للمركز

## المميزات

- ✅ **7 أقسام رئيسية**: الرئيسية، الملفات، المهام، الملاحظات، الامتحانات، الجدول، المجرة
- ✅ **قاعدة بيانات Room** لتخزين محلي سريع وآمن
- ✅ **Jetpack Compose** لواجهة مستخدم حديثة وسلسة
- ✅ **دعم RTL** كامل للغة العربية
- ✅ **الوضع الليلي** تلقائي
- ✅ **إضافة ملفات حقيقية من الجهاز** عبر منتقي النظام (SAF)، وتُنسخ داخل التطبيق وتُفتح بضغطة
- ✅ **فتح أنواع الملفات الشائعة** (PDF, DOCX, XLSX, PPTX, صور, فيديو, صوت) عبر التطبيقات المثبّتة على الجهاز (Intent `ACTION_VIEW`) — يلزم وجود تطبيق قارئ للنوع المطلوب
- ℹ️ **النسخ الاحتياطي** يحفظ البيانات الوصفية (المجلدات، المهام، الملاحظات، الامتحانات، المحاضرات، وسجلات الملفات) في ملف JSON؛ أما محتوى الملفات نفسه فيُنسخ داخل مجلد التطبيق ولا يُضمَّن في ملف النسخة حالياً

## التقنيات المستخدمة

- **Kotlin** - اللغة الأساسية
- **Jetpack Compose** - واجهة المستخدم
- **Room Database** - قاعدة البيانات المحلية
- **Coroutines & Flow** - البرمجة غير المتزامنة
- **Material 3** - التصميم
- **WorkManager** - جدولة تذكيرات المهام والامتحانات
- **DataStore Preferences** - حفظ التفضيلات (السمة، الألوان الديناميكية)
- **Hilt** - حقن التبعيات
- **Storage Access Framework (OpenDocument) + FileProvider** - اختيار الملفات وفتحها عبر تطبيقات النظام (لا توجد عارضات مدمجة؛ لا يُستخدم Apache POI أو ExoPlayer أو Coil)

## كيفية البناء

1. افتح المشروع في **Android Studio** (إصدار 2024.1 أو أحدث)
2. انتظر حتى ينتهي Gradle Sync
3. اضغط ▶ Run لتشغيل التطبيق على الجهاز أو المحاكي

## متطلبات النظام

- **Android Studio**: 2024.1+
- **JDK**: 17
- **Android SDK**: API 35 (Compile), API 26 (Minimum)
- **Gradle**: 8.7

## المكتبات المستخدمة

| المكتبة | الوظيفة |
|---------|---------|
| Room (مع migrations) | قاعدة البيانات المحلية |
| Hilt | حقن التبعيات |
| Coroutines / Flow | البرمجة غير المتزامنة وتدفقات البيانات |
| Jetpack Compose + Material 3 | واجهة المستخدم |
| Navigation Compose | التنقل بين الشاشات |
| WorkManager | تذكيرات المهام والامتحانات في الخلفية |
| DataStore Preferences | تفضيلات التطبيق |
| SAF + FileProvider | اختيار الملفات من الجهاز وفتحها عبر تطبيقاته المثبّتة |

> ملاحظة: لا يضم التطبيق عارضات ملفات مدمجة؛ تُفتح الملفات عبر تطبيقات النظام باستخدام `ACTION_VIEW`، ففتح مستند Office مثلاً يتطلب وجود تطبيق قارئ على الجهاز.

## ملاحظات

- التطبيق يعمل **بدون إنترنت** بالكامل
- جميع البيانات تُخزن محلياً على الجهاز
- يدعم **مشاركة الملفات** مع تطبيقات أخرى
- يدعم **النسخ الاحتياطي** والاستيراد
